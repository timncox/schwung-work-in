# Work In

Distribution repo for **Work In** — the `sound_generator` build of
[Work](https://github.com/timncox/schwung-work), a Schwung module for the
Ableton Move.

Twenty Tonverk-inspired FX machines on the live input, loaded into a Signal
Chain slot as the *source* rather than as an insert — so Move's own effects can
come after them.

## Install

schwung-manager → **Install Custom Module**, pointed at this repo.

## Source

All source, tests and documentation live in
**[timncox/schwung-work](https://github.com/timncox/schwung-work)**. This repo
exists only because the installer resolves one `release.json` per repo, so each
catalog id needs its own.
